# 🛒 خيرات ماركت

متجر إلكتروني بسيط وشكله نضيف لبيع المواد الغذائية والمنتجات المنزلية: سكر، أرز، شاي، زيت، بقوليات، مناديل ومنظفات.
الواجهة عربي بالكامل، ومعمولة للموبايل الأول، والدفع عند الاستلام.

> الخطة الكاملة للمشروع في [`docs/PLAN.md`](docs/PLAN.md).

## ✨ المميزات

**للعميل**
- تصفح المنتجات بالأقسام، وبحث ذكي بيفهم "رز" و"أرز" و"مكرونه" و"مكرونة".
- ترتيب بالسعر والعروض، وخصومات واضحة على المنتجات.
- سلة جانبية بتتحفظ على الجهاز، وشريط بيوضح فاضل كام على التوصيل المجاني.
- إتمام طلب في خطوة واحدة (الاسم، الموبايل، العنوان) والدفع كاش أو محفظة عند الاستلام.
- صفحة تأكيد فيها رقم الطلب، ومراحل الطلب، وزرار يبعت تفاصيل الطلب على واتساب.
- تتبع أي طلب برقم الطلب + رقم الموبايل، وقائمة بطلباتك القديمة من نفس الجهاز.

**لصاحب المتجر** (`/admin.html`)
- الرئيسية: طلبات ومبيعات النهارده، رسم لمبيعات آخر 7 أيام، المنتجات اللي قربت تخلص، والأكثر مبيعاً.
- الطلبات: فلترة بالحالة وبحث، وتغيير الحالة (جديد ← قيد التجهيز ← في الطريق ← تم التوصيل). الإلغاء بيرجّع الكميات للمخزن.
- تنبيه بصوت كل ما يوصل طلب جديد (كل 30 ثانية).
- المنتجات: إضافة وتعديل وحذف وإخفاء، الأسعار والخصومات والمخزون، ورفع لحد 8 صور لكل منتج (العميل بيقلّب فيهم من صفحة المنتج).
- الأقسام: إضافة وتعديل وحذف.
- الإعدادات: اسم المتجر، التليفون والواتساب، رسوم التوصيل، حد التوصيل المجاني، الحد الأدنى للطلب، شريط الإعلان، وتغيير كلمة السر.

## 🚀 التشغيل على جهازك

محتاج [Node.js](https://nodejs.org) نسخة 18 أو أحدث.

```bash
npm install
npm start
```

وبعدين افتح:
- المتجر: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin.html — كلمة السر الافتراضية: **`admin123`**

> ⚠️ **غيّر كلمة السر أول ما تدخل** من صفحة الإعدادات، أو حط `ADMIN_PASSWORD` قبل التشغيل.
> لوحة التحكم هتفضل تظهر لك تنبيه لحد ما تغيرها.

## ⚙️ الإعدادات (متغيرات البيئة)

انسخ `.env.example` لـ `.env` وعدّل فيه، أو حطهم في إعدادات الاستضافة:

| المتغير | الافتراضي | الوصف |
|--------|----------|-------|
| `PORT` | `3000` | البورت |
| `ADMIN_PASSWORD` | `admin123` | كلمة سر لوحة التحكم (لو اتغيرت من الإعدادات، اللي في الإعدادات هي اللي بتتحسب) |
| `DATA_DIR` | `./data` | مكان حفظ البيانات والصور المرفوعة |
| `TRUST_PROXY` | — | خليها `1` لو الموقع ورا proxy (Render، Railway، Nginx...) |

## 💾 البيانات

كل حاجة بتتحفظ في `data/db.json` والصور المرفوعة في `data/uploads/`.
- أول تشغيل بيعمل الملف تلقائياً بـ 28 منتج و6 أقسام جاهزين.
- **اعمل نسخة احتياطية** من فولدر `data` كل فترة.
- عايز ترجع المتجر لأول مرة؟ وقف السيرفر وامسح `data/db.json`.

## ☁️ الرفع على الإنترنت

### بـ Docker (أي سيرفر أو VPS)
```bash
docker build -t khairat-market .
docker run -d --name market -p 80:3000 \
  -e ADMIN_PASSWORD='كلمة-سر-قوية' \
  -v market-data:/app/data \
  --restart unless-stopped khairat-market
```

### Railway / Render / أي استضافة Node
- Build command: `npm install`
- Start command: `npm start`
- ضيف `ADMIN_PASSWORD` و `TRUST_PROXY=1`.
- **مهم:** اربط Volume / Persistent Disk على `DATA_DIR` (مثلاً `/app/data`) عشان الطلبات متضيعش مع كل deploy.

```
server/
  index.js      تشغيل السيرفر
  app.js        كل الـ API (المتجر + لوحة التحكم)
  db.js         التخزين في ملف JSON
  auth.js       تسجيل دخول لوحة التحكم والحماية
  validate.js   التحقق من البيانات
  seed.js       المنتجات والإعدادات المبدئية

  index.html    الصفحة الرئيسية
  checkout.html إتمام الطلب
  order.html    تأكيد وتتبع الطلب
  admin.html    لوحة التحكم
  css/ js/ images/ fonts/
scripts/
  generate-product-images.js   بيولد رسومات المنتجات (npm run images)
test/
  api.test.js
```

# 🛒 جملة بيتك

> **طلبية بيتك للشهر كله.. مرة واحدة وبسعر الجملة لحد بابك**
> معمول مخصوص لكبار السن والمرضى وكل أم وقتها ضيق • نخدم الآن: الهرم • فيصل

متجر لبيع **خزين البيت للشهر بأسعار الجملة**: سكر، أرز، زيت، شاي، بقوليات، مناديل ومنظفات بالكرتونة والشيكارة.
الفكرة إن العميل يطلب خزين الشهر كله مرة واحدة (مش حاجة واحدة كل شوية)، ويوفر عن أسعار السوق.
الواجهة عربي بالكامل، ومعمولة للموبايل الأول، والدفع عند الاستلام.

> الخطة الكاملة للمشروع في [`docs/PLAN.md`](docs/PLAN.md).

## ✨ المميزات

**للعميل**
- **باقات جاهزة للعيلة**: باقة لعيلة صغيرة ومتوسطة وكبيرة، تتضاف كلها للسلة بضغطة، وبعدين يعدّل عليها براحته.
- كل منتج بسعر الجملة جنب سعر السوق، ونسبة التوفير، وسعر الكيلو/اللتر/الرول.
- تصفح المنتجات بالأقسام، وبحث ذكي بيفهم "رز" و"أرز" و"مكرونه" و"مكرونة".
- ترتيب بالسعر والتوفير.
- سلة جانبية بتتحفظ على الجهاز، بتوضح الحد الأدنى للطلب والتوصيل المجاني وإجمالي التوفير عن السوق.
- زرار **"كرر نفس الطلبية"** في صفحة الطلب، عشان الشهر الجاي يطلب نفس الحاجات بضغطة.
- مناطق التوصيل (الهرم وفيصل) بتظهر في أول الموقع، والعميل بيختار منطقته من قائمة وهو بيطلب.
- زرار **"اطلب واتساب"** ثابت في الصفحة للناس اللي مش متعودة على الطلب من المواقع.
- إتمام طلب في خطوة واحدة (الاسم، الموبايل، العنوان) والدفع كاش أو محفظة عند الاستلام.
- صفحة تأكيد فيها رقم الطلب، ومراحل الطلب، وزرار يبعت تفاصيل الطلب على واتساب.
- تتبع أي طلب برقم الطلب + رقم الموبايل، وقائمة بطلباتك القديمة من نفس الجهاز.

**لصاحب المتجر** (`/admin.html`)
- الرئيسية: طلبات ومبيعات النهارده، رسم لمبيعات آخر 7 أيام، المنتجات اللي قربت تخلص، والأكثر مبيعاً.
- الطلبات: فلترة بالحالة وبحث، وتغيير الحالة (جديد ← قيد التجهيز ← في الطريق ← تم التوصيل). الإلغاء بيرجّع الكميات للمخزن.
- تنبيه بصوت كل ما يوصل طلب جديد (كل 30 ثانية).
- المنتجات: إضافة وتعديل وحذف وإخفاء، سعر الجملة وسعر السوق، العبوة وعدد الوحدات فيها، المخزون، ورفع لحد 8 صور لكل منتج (العميل بيقلّب فيهم من صفحة المنتج).
- الخزين الجاهز: إضافة وتعديل وحذف وإخفاء، واختيار المنتجات والكميات (السعر بيتحسب لوحده).
- الأقسام: إضافة وتعديل وحذف.
- الإعدادات: اسم المتجر، العنوان الكبير، التليفون والواتساب، **المناطق اللي بنوصلها**، رسوم التوصيل، حد التوصيل المجاني، الحد الأدنى للطلب، شريط الإعلان، وتغيير كلمة السر.

## 🚀 التشغيل على جهازك

محتاج [Node.js](https://nodejs.org) نسخة 18 أو أحدث.

```bash
npm install
npm start
```

وبعدين افتح:
- المتجر: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin.html — كلمة السر الافتراضية: **`admin123`**

> ⚠️ **غيّر كلمة السر أول ما تدخل** من صفحة الإعدادات، أو حط `ADMIN_PASSWORD` قبل التشغيل.
> لوحة التحكم هتفضل تظهر لك تنبيه لحد ما تغيرها.

## ⚙️ الإعدادات (متغيرات البيئة)

انسخ `.env.example` لـ `.env` وعدّل فيه، أو حطهم في إعدادات الاستضافة:

| المتغير | الافتراضي | الوصف |
|--------|----------|-------|
| `PORT` | `3000` | البورت |
| `ADMIN_PASSWORD` | `admin123` | كلمة سر لوحة التحكم (لو اتغيرت من الإعدادات، اللي في الإعدادات هي اللي بتتحسب) |
| `DATA_DIR` | `./data` | مكان حفظ البيانات والصور المرفوعة |
| `TRUST_PROXY` | — | خليها `1` لو الموقع ورا proxy (Render، Railway، Nginx...) |

## 💾 البيانات

كل حاجة بتتحفظ في `data/db.json` والصور المرفوعة في `data/uploads/`.
- أول تشغيل بيعمل الملف تلقائياً بـ 29 منتج جملة و6 أقسام و3 خزين جاهز.
- الإعدادات المبدئية: الحد الأدنى للطلب 1000 جنيه، والتوصيل 50 جنيه، ومجاني فوق 2500 جنيه (تتغير من لوحة التحكم).
- لو كنت شغلت نسخة قديمة قبل كده، البيانات القديمة بتتحدث لوحدها. ولو عايز منتجات الجملة الجديدة امسح `data/db.json`.
- **اعمل نسخة احتياطية** من فولدر `data` كل فترة.
- عايز ترجع المتجر لأول مرة؟ وقف السيرفر وامسح `data/db.json`.

## ☁️ الرفع على الإنترنت

### أسهل طريقة: Render بضغطة واحدة
المشروع فيه ملف `render.yaml` جاهز بكل الإعدادات.

1. اعمل حساب على [render.com](https://render.com) واربطه بحساب GitHub بتاعك.
2. افتح الرابط ده: https://render.com/deploy?repo=https://github.com/abosalah-dev/ecommerce
3. اضغط **Apply** واستنى دقيقتين، وهيديك رابط الموقع (زي `gomlet-beitak.onrender.com`).
4. كلمة سر لوحة التحكم اتعملت أوتوماتيك: هتلاقيها في صفحة الخدمة على Render ← **Environment** ← `ADMIN_PASSWORD`.

> الإعداد ده بيستخدم خطة **Starter** (حوالي 7 دولار في الشهر) ومعاها هارد 1 جيجا (حوالي ربع دولار)، عشان الطلبات والصور تفضل محفوظة.
> الخطة المجانية بتمسح البيانات مع كل إعادة تشغيل، فمتنفعش لمتجر حقيقي.
> بعد الرفع تقدر تربط دومين باسمك من **Settings ← Custom Domains**.

### بـ Docker (أي سيرفر أو VPS)
```bash
docker build -t gomlet-beitak .
docker run -d --name market -p 80:3000 \
  -e ADMIN_PASSWORD='كلمة-سر-قوية' \
  -v market-data:/app/data \
  --restart unless-stopped gomlet-beitak
```

### Railway / Render / أي استضافة Node
- Build command: `npm install`
- Start command: `npm start`
- ضيف `ADMIN_PASSWORD` و `TRUST_PROXY=1`.
- **مهم:** اربط Volume / Persistent Disk على `DATA_DIR` (مثلاً `/app/data`) عشان الطلبات متضيعش مع كل deploy.

# خطة مشروع "خيرات ماركت" 🛒

متجر إلكتروني لبيع **خزين البيت للشهر بأسعار الجملة** (سكر، أرز، شاي، مناديل، زيوت، بقوليات، منظفات...)
بالكرتونة والشيكارة، بواجهة عربية (RTL) سهلة، والدفع عند الاستلام.

> الفكرة: مش زي تطبيقات التوصيل اللي الناس بتطلب منها حاجة واحدة. هنا العميل بيطلب خزين الشهر كله مرة واحدة ويوفر عن أسعار السوق.

## 1. الأهداف
- شكل بسيط ونظيف ومريح على الموبايل قبل الكمبيوتر.
- العميل يقدر يتصفح، يبحث، يضيف للسلة، ويطلب في أقل من دقيقة.
- صاحب المتجر يقدر يدير المنتجات والأسعار والمخزون والطلبات من لوحة تحكم بدون أي خبرة برمجية.
- تشغيل سهل جداً: أمر واحد `npm start` بدون قاعدة بيانات خارجية.

## 2. التقنيات المختارة
| الجزء | الاختيار | السبب |
|------|---------|-------|
| السيرفر | Node.js + Express | خفيف ومشهور وسهل الاستضافة |
| التخزين | ملف JSON (`data/db.json`) بكتابة آمنة (atomic) | بدون إعداد قاعدة بيانات، مناسب لمتجر صغير/متوسط |
| الواجهة | HTML + CSS + JavaScript بدون أي build | سريعة، سهلة التعديل، تشتغل على أي استضافة |
| الخط | Cairo (مستضاف داخل المشروع) | خط عربي واضح وجميل ويشتغل بدون إنترنت خارجي |
| الصور | رسومات SVG مولدة للمنتجات + إمكانية رفع صور حقيقية من لوحة التحكم | شكل موحد وخفيف |
| الاختبارات | `node:test` المدمج | بدون مكتبات إضافية |

## 3. الصفحات
### للعميل
1. **الرئيسية** (`/`): شريط إعلان، بانر، أقسام، بحث، ترتيب، شبكة المنتجات، سلة جانبية.
2. **إتمام الطلب** (`/checkout.html`): بيانات العميل (الاسم، الموبايل، المنطقة، العنوان، ملاحظات) + طريقة الدفع + ملخص الطلب.
3. **الطلب / التتبع** (`/order.html`): تأكيد الطلب برقم الطلب، مراحل الحالة، زرار إرسال الطلب على واتساب، وتتبع أي طلب برقم الطلب + الموبايل.

### لصاحب المتجر (`/admin.html`)
1. **الرئيسية**: إحصائيات (طلبات اليوم، مبيعات، طلبات جديدة، منتجات قليلة المخزون).
2. **الطلبات**: قائمة بفلترة حسب الحالة، تفاصيل الطلب، تغيير الحالة (جديد ← قيد التجهيز ← في الطريق ← تم التوصيل / ملغي). الإلغاء يرجّع المخزون.
3. **المنتجات**: إضافة / تعديل / حذف، السعر، السعر قبل الخصم، المخزون، الإظهار/الإخفاء، رفع صورة.
4. **الأقسام**: إضافة / تعديل / حذف.
5. **الإعدادات**: اسم المتجر، رقم التليفون والواتساب، العنوان، رسوم التوصيل، حد التوصيل المجاني، الحد الأدنى للطلب، نص شريط الإعلان، تغيير كلمة السر.

## 4. قواعد العمل (Business rules)
- الأسعار بالجنيه المصري. السيرفر **يعيد حساب** الأسعار من قاعدة البيانات ولا يثق في أسعار المتصفح.
- التحقق من المخزون وقت الطلب، وخصم الكمية تلقائياً، وإرجاعها عند الإلغاء.
- رسوم توصيل ثابتة، ومجاني فوق حد معين (من الإعدادات).
- رقم الموبايل لازم يكون مصري صحيح (`01xxxxxxxxx`).
- حد أقصى للكمية من كل منتج في الطلب الواحد (من الإعدادات).

## 5. الأمان
- لوحة التحكم بكلمة سر (من متغير البيئة `ADMIN_PASSWORD` أو تتغير من الإعدادات وتتخزن مشفرة scrypt).
- جلسة بكوكي `HttpOnly` + `SameSite=Strict`، وحماية من تخمين كلمة السر (Rate limit).
- كل النصوص بتتعرض في الصفحة بطريقة آمنة (بدون innerHTML لبيانات المستخدم) لمنع XSS.
- حدود لحجم الطلبات ورفع الصور (PNG/JPG/WEBP فقط، بحد أقصى 2 ميجا).
- Security headers أساسية.

- ✅ سعر الوحدة (سعر الكيلو / اللتر / الرول) بيتحسب ويظهر للعميل.
- ✅ "خزين الشهر الجاهز" لعيلة صغيرة ومتوسطة وكبيرة، يتضاف للسلة بضغطة، ويتدار من لوحة التحكم.
- ✅ إجمالي التوفير عن السوق بيظهر في السلة وإتمام الطلب وصفحة الطلب.
- ✅ حد أدنى للطلب 1000 جنيه، وتوصيل مجاني فوق 2500 جنيه.
- ✅ زرار "كرر نفس الخزين" لطلب الشهر الجاي بضغطة.
- ✅ متوسط قيمة الطلب في لوحة التحكم.

## 8. أفكار للمستقبل
- اشتراك شهري: الخزين يتبعت أوتوماتيك كل شهر في ميعاد ثابت.
- تذكير على واتساب لما الشهر يقرب يخلص.
- دفع أونلاين (Paymob / Fawry).
- حسابات للعملاء وسجل الطلبات.
- كوبونات خصم.
- رسوم توصيل مختلفة حسب المنطقة.
- إشعار واتساب/إيميل تلقائي لصاحب المتجر عند كل طلب جديد.
- الانتقال لقاعدة بيانات (PostgreSQL / SQLite) لو حجم الطلبات كبر.
